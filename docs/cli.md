# CLI

The executable name is `devcert`.

Supported top-level options:

* `--help`
* `--version`
* `--json`

Required command groups:

* `ca`
* `issue`
* `sign-csr`
* `pkcs12`
* `install`
* `uninstall`
* `inspect`

Human-readable text is routed through the localization catalog. JSON output is
schema versioned and deterministic.
